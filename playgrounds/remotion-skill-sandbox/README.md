# Remotion Skill Sandbox

这是一个和现有网站完全隔离的 Remotion 试验目录。

## 启动

```bash
npm install
npm run dev
```

这个沙盒已经固定使用你本机的 Google Chrome，不会再去下载 Remotion 自己的浏览器。

## 渲染

```bash
npm run render
```

输出文件会在：

```bash
out/product-bumper.mp4
```

## 现在有什么

- 一个最小可运行的 Remotion 项目
- 一个 `ProductBumper` 示例 composition
- 白底、黑字、轻微入场动效

你后面可以直接让我在这个目录里继续用 `remotion` skill 扩展，而不会碰现有网站文件。
