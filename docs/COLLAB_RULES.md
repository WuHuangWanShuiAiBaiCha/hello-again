# Collaboration Rules

## Approval First

- I may propose an execution step, but before every execution step I must get user approval.
- Any direct modification requires approval before execution.
- Deleting files, adding files, adding documents, creating new assets, replacing assets, or changing project structure require especially explicit approval before execution.

## Current Project Default

- Planning, analysis, research, comparison, and proposals are allowed by default.
- Actual execution must wait for approval each time.
- HTML, CSS, JS, images, assets, text files, local documents, downloads, replacements, deletions, and newly created files are all included in this rule.

## Git Rule

- Every modification version must be saved in git.
- Do not skip git checkpoints after changes in this project.
